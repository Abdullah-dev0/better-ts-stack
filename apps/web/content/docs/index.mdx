## What is better-ts-stack?

better-ts-stack is an interactive CLI that generates TypeScript projects. You choose the framework, database, authentication, AI chat, and Docker setup from a few prompts, and the CLI writes a project that is ready to install and run: one app, or a Turborepo with a web app and an api.

<Callout type="info" title="Good for">

- Starting a new TypeScript backend or full-stack project
- Prototyping an API with Express or NestJS
- Learning how a TypeScript project is structured
- Using the same project setup across a team

</Callout>

## Quick Start

<Steps>

<Step>
### Run the CLI

<Tabs items={['npx (recommended)', 'Global install', 'pnpm dlx', 'bunx']}>
  <Tab value="npx (recommended)">
    ```bash
    npx better-ts-stack
    ```
  </Tab>
  <Tab value="Global install">
    ```bash
    npm install -g better-ts-stack
    better-ts-stack
    ```
  </Tab>
  <Tab value="pnpm dlx">
    ```bash
    pnpm dlx better-ts-stack
    ```
  </Tab>
  <Tab value="bunx">
    ```bash
    bunx better-ts-stack
    ```
  </Tab>
</Tabs>
</Step>

<Step>
### Answer the prompts

The CLI asks, in order (every prompt can also be answered with a [flag](/docs/usage#flags)):

1. **Project name** - becomes your folder name and `package.json` name
2. **Monorepo** - one project, or a Turborepo with a web app and an api?
   - **Yes**: select the web app (Next.js or TanStack Start) and the api (Express, NestJS, or none) instead of the application type
3. **Application type** - `Backend API` or `Full-stack`
   - **Backend**: select a framework (Express or NestJS)
   - **Full-stack**: select a frontend framework (Next.js 16 or TanStack Start)
4. **Database type** - `none`, `PostgreSQL`, or `MongoDB`
5. **ORM/ODM** (only shown when a database is selected)
   - PostgreSQL -> `Prisma` or `Drizzle`
   - MongoDB -> `Mongoose`
6. **Package manager** - `npm`, `pnpm`, or `bun`
7. **Docker** - include Docker configuration? (not for a monorepo yet)
8. **Authentication** - add auth?
   - Better Auth for every framework: email and password, email verification, password reset, and GitHub and Google sign-in
   - Next.js / TanStack: only prompted if a database was selected
9. **AI chat** - none, Vercel AI SDK, or TanStack AI: a streaming chat route, plus a chat page on Next.js and TanStack Start
10. **Which app owns users and data** - monorepo with an api only: the web app (easiest) or the api runs auth, the database, and AI chat
11. **Rate limiting** - Express / NestJS only: limit requests per IP?
12. **CI** - add a GitHub Actions workflow?
13. **VS Code** - add workspace settings and recommended extensions?
14. **Git** - initialize a repository?
15. **Install dependencies** - run the install command now?

<Callout type="info">
  The CLI does not ask for a port number. The server port defaults to `3000`
  via the `PORT` environment variable.
</Callout>
</Step>

<Step>
### Start developing

```bash
cd your-project-name
npm install   # skip if you chose to install during setup
npm run dev
```

</Step>

</Steps>

## Requirements

- **Node.js** 24.0.0 or higher
- **Package manager** - npm, pnpm, or bun

<Callout type="warn">
  Check your Node.js version before running: `node --version`
</Callout>
